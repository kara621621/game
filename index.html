🎁 오늘의 결과물: 캔바 AI 웹 게임 + 나만의 프롬프트

🪄 프롬프트란?

프롬프트는 AI에게 보내는 부탁 문장이에요. 무엇을 만들지, 어떻게 움직일지, 어떤 규칙인지 자세하게 알려주면 좋아요!

💡 예: “피하기 게임을 만들어줘”보다 “우주에서 운석을 피하는 게임을 만들어줘. 방향키로 움직이고, 운석을 피하면 1점을 줘”가 더 좋아요.

✍️ 나의 게임 설계도 → 프롬프트

활동지의 ①~⑥을 차례대로 작성해요. 2차시 기획 카드의 게임 이름·주인공·장애물·배경도 참고해요.

캔바 열기 ↗
위의 ①~⑥을 작성한 뒤 ‘내 프롬프트 만들기’를 눌러요. ‘○○라는 웹 게임을 만들어줘. 1. ... 2. ... 3. ... 4. ... 5. ... 6. ...’

여섯 항목이 번호 순서대로 하나의 프롬프트로 완성돼요. 복사한 문장을 캔바 AI에 그대로 붙여 넣으세요.

캔바 AI 사용은 학교·선생님이 안내한 계정과 방법을 따라요. 캔바에서 제공되는 기능은 계정에 따라 다를 수 있어요.

v3.0 · 캔바 AI

4차시 · 내 게임을 업그레이드하자!

새 기능을 2개 더하고 친구들과 플레이하며 의견을 나눠요.

🎁 오늘의 결과물: 업그레이드 웹 게임 + 친구 피드백 카드

🛠️ 업그레이드 메뉴판 (2개 선택)

캔바 열기 ↗
'운석 피해라!'라는 웹 게임을 만들어줘. 우주에서 로봇이 떨어지는 운석을 피하는 게임이야. 1. 첫 화면에 큰 제목, '최고 기록: ○점', '시작하기' 버튼을 보여줘. 2. 로봇은 화면 아래에 있고, 화면 터치, 아래쪽 왼쪽·오른쪽 큰 버튼(누르고 있으면 계속 이동), 키보드 화살표 키로 움직여. 3. 운석은 1초마다 위쪽 무작위 위치에서 떨어지고, 시간이 지날수록 조금씩 빨라져. 4. 운석을 피하면 1점, 가끔 떨어지는 별을 먹으면 5점. 점수·하트·최고 기록을 화면 위에 카드처럼 보여줘. 5. 하트는 3개. 운석에 닿으면 하트가 1개 줄고 화면이 살짝 흔들려. 하트가 0개면 게임 오버. 6. 게임 오버 화면에 최종 점수와 '다시 하기' 버튼, 기록을 넘으면 '최고 기록 갱신!'을 보여줘. 7. 최고 점수는 저장해서 껐다 켜도 남게 해줘. 다시 하기를 누르면 점수와 하트는 처음으로 돌아가. 8. 어두운 우주 배경, 반짝이는 별, 귀엽고 신나는 분위기. 서피스 가로 화면에서 스크롤 없이, 큰 글씨, 모든 글은 한글로.
기능 2개를 고르고 ‘업그레이드 문장 만들기’를 눌러요.

AI에게는 기능을 한 번에 하나씩 부탁하고, 플레이해서 확인한 뒤 다음 기능을 추가해요.

🪲 버그가 있다면 이렇게 말해요

무엇이 → 어떻게 잘못됐고 → 어떻게 되면 좋은지 차례로 말하기!

“다시 하기를 누르면 점수가 0으로 돌아가지 않아. 다시 하기를 누를 때 점수와 하트를 처음 상태로 돌려줘.”
